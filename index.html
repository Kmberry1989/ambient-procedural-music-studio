Sound sources — what's under the hood

Synth first, samples second. Every sound in this studio — drums, strings, pads, effects — is synthesised live with the Web Audio API: zero audio files, instant first sound, works offline, and no licences to track. That's the route the research recommends for a small touch-first studio, and it's how the string section here is built (detuned sawtooths, vibrato, slow bow attack) rather than from recordings.

If real recordings are added later, the clean-licensed shortlist is VSCO 2 Community Edition (CC0 — orchestral strings, winds and percussion; the full library is ~3 GB, so only a few pruned notes per section would ship) and FreePats World & Rare Percussion (CC0 hand percussion — cajón, conga, shaker, the sounds behind the World drum kit). Philharmonia's samples are deliberately not used: their terms don't allow making the samples available as a sampler instrument.

Frameworks & pitch. Tone.js (v15) was the other shortlisted framework — this page stays dependency-free native Web Audio instead, using the same building blocks. The hum tracker uses a YIN-style autocorrelation detector (the approach behind the Pitchfinder library): there is no turnkey, maintained browser autotune library, so detection + snapping to the scale is the robust design.
