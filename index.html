How it reads you: motion tracking finds your moving hand (bright dot) and face region (box). A sharp downward flick = downbeat accent (kick + swell), raising both / large motion = crescendo, holding still = diminuendo, head nod = cue. Hand height drives expression volume, side-to-side drives brightness — just like a conductor's left hand shapes phrasing while the right keeps time. If your browser supports face detection it is used when available; otherwise face motion in the upper frame is tracked. Deny camera and everything else still works by touch.
Every note is synthesised in your browser with the Web Audio API — chords evolve bar by bar, melodies wander and vary, and each loop returns to its first chord so it can run indefinitely. Key, tempo and time-signature changes land on the next bar, so the music never stutters.
